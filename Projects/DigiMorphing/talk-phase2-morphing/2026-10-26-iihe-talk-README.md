# IIHE Tracker DPG talk, 27 Oct 2026: Phase-2 digi morphing

Beamer deck `phase2_morphing.tex` (theme `beamerthemecmstalk.sty`, copied from the Higgs 2026 deck with a
configurable footer). Build with `pdflatex phase2_morphing.tex` twice; there is no XeLaTeX on the laptop.

`figures/` and the PDF are gitignored. The plots live on EOS (`/eos/user/c/cgupta/phase2morph/plots`), and two
crops come from CERN-restricted workshop slides (Bartosik slide 12, Schulz slide 4). Run `./fetch_figures.sh` to
rebuild them on a new machine.

`morph_example.tex` holds the toy closing on the title slide and slide 9. It was generated by a script that applies
the kernel's rules exactly (4 clusters become 2, and the isolated pixel 3 columns away stays separate).

29 main slides plus 6 backup slides:
1. Workshop lessons
2. Phase-2 module sizes
3. A GPU primer
4. Work division
5. Algorithm (strips, why 44, halo 2, block size)
6. Four code slides
7. Validation plots
8. Configuration, the files table, why a new namespace and a new header, and `git diff --stat`
