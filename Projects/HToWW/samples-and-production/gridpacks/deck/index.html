Why: two problems in the central H+c/H+b → WW samples, and no 3FS WW

1. LHE scale/PDF weights wrong (gridpack build)

  • all scale variations ≈ ×2 nominal, PDF replicas / member 0 ≈ 2.26
  • cause: genproductions NLO workflow appends reweight_scale/PDF = False and runs the python systematics module, which ignores the running charm Yukawa of _mg5amc.patch

2. FxFx merging misconfigured (fragment)

  • 7 WW requests lack JetMatching:jetAlgorithm = 2, etaJetMax = 999., coneRadius = 1. → veto only at |η|<2.5, R = 0.7
  • forward 1-jet events 7× rarer; not fixable by reweighting

3. No Run 3 3FS H→WW exists

  • DAS: Run 3 3FS H+c only for H→γγ; 3FS WW only Run 2 UL. Needed for the 3FS/4FS flavour-scheme treatment (LHCHWG-2026-007)

  • Physics cards (proc, run, param, _mg5amc.patch, extramodels) are byte-identical to the official clean H→γγ 4FS gridpack. The bug is purely in the build scripts.

3FS validation: definitions and commands

  • LHE: LHEPart status 1; Higgs (25); leading charm (|pdgId| 4); N outgoing partons (q, g).
  • c-hadron: GenPart status 2, open charm (4xx/4xxx, charmonium excluded), weakly decaying, not from a b-hadron, |η| < 2.5 (same definition as fs_unc/gen/derive_chad.py used for the flavour-scheme systematic); first bin = none or pT < 5 GeV, as in the systematic.
  • GenJets: pT > 30, |η| < 4.7, removed within ΔR < 0.4 of status-1 prompt e/μ/γ (pT>5) and GenVisTau (pT>15).
  • Leptons: status-1 prompt or direct-τ-decay e/μ.
  • χ²: normalised shapes, Σ(p1−p2)²/(σ1²+σ2²) with σ² from Σw², ndf = bins − 1.
  • A first pass (2026-11-04, ¼ of the statistics, no τ cleaning) gave LHE Higgs pT 28/12 and GenJet pT 33/8. With full statistics the LHE value became 11.3/12; the jet differences stayed (attributed to the decay). First-pass outputs kept in out_v1/.
