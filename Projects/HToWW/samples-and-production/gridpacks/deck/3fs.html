Summary

  • No Run 3 3FS H+c → WW sample exists (only H→γγ in Run 3, and H→WW in Run 2 UL). It is needed for the 3FS/4FS flavour-scheme treatment (LHCHWG-2026-007).
  • The official Run 3 3FS H+c gridpack has an undecayed Higgs and correct weights, so it is reused unchanged. Only the fragment is new: H→WW→ℓν decay in Pythia.
  • Validated with a 10M-event private production (full chain to NanoAOD, 4 eras) of exactly this gridpack + fragment:
    • σ = 54.97 ± 0.32 fb, negative-weight fraction 0.397 (official 0.396)
    • all 9 scale variations within 0.5% of official
    • all production-level shapes agree with official 3FS H→γγ; the decay agrees with Run 2 3FS H→WW

  • Official Run 3 3FS H+c gridpack (p p > h c c~ [QCD], MG5_aMC 2.9.9, no MadSpin). Its cards, including the running-Yukawa _mg5amc.patch, are the official ones on GitHub:

  • Validation logic: production-level quantities do not depend on the Higgs decay, so private H→WW must reproduce the official 3FS H→γγ NanoAOD made from the same gridpack. The decay is checked against the official Run 2 UL18 3FS H→WW.
  • Statistics used: private 500k events, official γγ 1.84M, UL18 WW 1.65M. With ≈ 40% negative weights the effective statistics are ≈ 4% of that.

Validation: definitions

  • LHE: LHEPart status 1; Higgs (25); leading charm (|pdgId| 4); N outgoing partons (q, g).
  • c-hadron: GenPart status 2, open charm (charmonium excluded), weakly decaying, not from a b-hadron, |η| < 2.5; first bin = none or pT < 5 GeV.
  • GenJets: pT > 30, |η| < 4.7, removed within ΔR < 0.4 of status-1 prompt e/μ/γ (pT>5) and GenVisTau (pT>15).
  • Leptons: status-1 prompt or direct-τ-decay e/μ.
  • χ²: normalised shapes, Σ(p1−p2)²/(σ1²+σ2²) with σ² from Σw², ndf = bins − 1.

Assumptions, open items, provenance

  • PDF weights: NanoAOD has no LHEPdfWeight for this gridpack (official too). The LHE-level replica check comes from a 1000-event test job.
  • GenJets: decay-dependent differences (slide 3fs-jets); not used as a pass/fail criterion.
  • el8: the gridpack is slc7 (as used centrally for H→γγ); not rebuilt on el8.
  • Event numbers: [N events] per era is still open.
  • Use of private samples: internal cross-checks only; they cannot replace a central sample in public results.
  • Sources: validation /eos/user/c/cgupta/HToWW/gridpack_val_2026-11/; production /eos/user/c/cgupta/HToWW/freshprod_3fs/.
