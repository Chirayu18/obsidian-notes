HToWW · Framework r2 · 6 Nov 2026 · agent-reported, not independently validated

The current b-hive model ignores event weights

  • Corrected review claim: writing a normalised weight column does not make this model consume it.
  • What the current processor reads: input features and class labels. The merged training weight is a class-abundance weight.
  • Practical consequence: generator sign and physics normalisation do not enter the training loss. A negative-weight simulation event is treated like any other event of its class.
  • v11 used the same convention. This work records it; it does not decide whether to change it.

Training weights need a physics decision. Template normalisation is a separate step.
